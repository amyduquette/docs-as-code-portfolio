# Amy Duquette

**Technical Writer**  |  [LinkedIn](https://www.linkedin.com/in/amyduq1/)

This repository shows documentation systems I created and maintained as the first dedicated technical writer at an AI developer tools company. It includes agent skills, standards, validation, and automation, with company-specific details replaced by generic examples.

## Agent skills

- [CLI release](agent-skills/cli-release/SKILL.md): Checks released code and keeps related documentation up to date.
- [Add an integration to product docs](agent-skills/add-tool-page/SKILL.md): Creates an integration guide for the product documentation.
- [Add the product to other docs](agent-skills/add-product-to-other-docs/SKILL.md): Documents the product in another project's documentation.
- [Documentation review](agent-skills/review-docs/SKILL.md): Reviews documentation for accuracy, clear steps, and consistent terminology.
- [Documentation writing](agent-skills/writing-docs/SKILL.md): Applies shared writing and content standards.

## Documentation standards

- [Agent instructions](docs-standards/AGENT_INSTRUCTIONS.md): Guides documentation agents working in the repository.
- [Style guide](docs-standards/STYLE_GUIDE.md): Defines voice, terminology, and formatting.
- [Content architecture](docs-standards/CONTENT_ARCHITECTURE.md): Defines page types, structure, and navigation.
- [Agent workflows](docs-standards/AGENT_WORKFLOWS.md): Defines drafting and editorial review practices.
- [Documentation validation](docs-standards/DOCS_VALIDATION.md): Records checks, commands, and CI coverage.
- [Documentation operations](docs-standards/DOCS_OPERATIONS.md): Maps active and planned documentation systems.

## Documentation workflows

- [Documentation link checker](workflows/link-checker/README.md): Checks routes, anchors, assets, and navigation links.
- [Reader-signal digest](workflows/reader-signal-digest/README.md): Turns documentation analytics into a weekly planning digest.
- [Weekly docs changelog](workflows/weekly-docs-changelog/README.md): Summarizes reader-facing changes from merged documentation pull requests.
