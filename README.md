This repository contains documentation engineering systems I created and maintained as the first dedicated technical writer at an AI developer tools company. The agent skills, standards, validation tooling, and automated workflows helped engineers and AI agents contribute accurate, consistent documentation. Company-specific details have been replaced with generic examples.
